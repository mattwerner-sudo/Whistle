## Regressions (after < baseline)

Four schools dropped emails in the after pass:

- Ole Miss (SEC): 290 → 0  ← directory-fetch failure, not a parser regression
- Liberty (CUSA): 195 → 162 (−33)  ← cors-proxy variability, not bio-merge
- Coastal Carolina (Sun Belt): 136 → 133 (−3)
- West Virginia (Big 12): 230 → 229 (−1)

The Ole Miss drop is a transient site-fetch failure during the after pass
(both passes use the live network). Coastal Carolina and West Virginia are
within normal run-to-run noise from the Sidearm directories paginating
differently.

The Liberty regression was investigated separately (Task #32). Bio
enrichment is innocent — `bioRecovered: 0` for Liberty, and the merge in
`enrichMissingEmailsFromBio` only fills empty `email` fields, never
overwrites existing ones. The real cause is upstream cors-proxy
variability: the after pass got a half-sized HTML payload (1.2MB vs 2.5MB)
with `containerHints: ["data-cfemail", ...]` and 0 mailto links, while the
baseline got the rich mailto-bearing variant (2.5MB, 272 mailto links).
Cloudflare's email-protection feature rewrites mailto links into
`data-cfemail` tokens for some proxy IPs and trims the surrounding markup
at the same time, so the parser sees fewer staff containers (221 vs 277).
Mitigation landed in `fetchWithProxy`: it now scores every proxy response
and prefers the mailto-bearing payload instead of unconditionally taking
the first ok-looking one. Test: `tests/cors-proxy-fetch.test.ts`.
