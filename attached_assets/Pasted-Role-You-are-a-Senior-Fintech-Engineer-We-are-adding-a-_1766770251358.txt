Goal:

Checkout: Redirect users to a Stripe Checkout page.

Webhooks: Securely listen for payment events to update the database.

Portal: Allow users to manage their billing (cancel/upgrade) via the Stripe Customer Portal.

Sync: Ensure the local users table matches Stripe's status exactly.

Please execute the following 5 steps:

Step 1: Install Dependencies
npm install stripe

Step 2: Update Database Schema
Update shared/schema.ts to track subscription details.

TypeScript

Step 3: Configure the Server & Webhooks (Critical)
Update server/index.ts. Crucial: You must set up the Webhook route before the global express.json() middleware because Stripe requires the raw request body for signature verification.

TypeScript

// server/index.ts (Snippet - Place this BEFORE other middleware)
import express from "express";
import { registerStripeWebhooks } from "./routes/stripe";

const app = express();

// 1. Raw Webhook Route (Must be first)
app.post("/api/webhooks/stripe", express.raw({ type: "application/json" }), registerStripeWebhooks);

// 2. Global Middleware
app.use(express.json());
app.use(express.urlencoded({ extended: false }));
// ... rest of your app ...
Step 4: Implement the Stripe Logic
Create server/routes/stripe.ts. This handles the heavy lifting.

Requirements for this file:

Init: Initialize Stripe with process.env.STRIPE_SECRET_KEY.

POST /api/checkout: Creates a session.

mode: 'subscription'

success_url: https://YOUR_DOMAIN/dashboard?success=true

cancel_url: https://YOUR_DOMAIN/pricing?canceled=true

Metadata: Pass userId so the webhook knows who paid.

POST /api/portal: Creates a portal session using the user's stripeCustomerId.

registerStripeWebhooks (The Listener):

Verify signature using stripe.webhooks.constructEvent.

Handle checkout.session.completed: Update user -> subscriptionStatus: 'active', save stripeCustomerId.

Handle invoice.payment_succeeded: Update currentPeriodEnd.

Handle customer.subscription.deleted: Set status to canceled or inactive.

Step 5: Build the Pricing UI
Create client/src/pages/pricing.tsx.

Visuals: A clean Pricing Card component.

Logic:

If user.subscriptionStatus === 'active', show "Manage Subscription" (calls /api/portal).

If inactive, show "Subscribe $99/mo" (calls /api/checkout).

Handle the ?success=true URL param to show a "Welcome Back!" toast.
